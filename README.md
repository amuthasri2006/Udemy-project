# Udemy-project
 Udemy Clone Website

A simple Udemy Clone Website created using HTML and CSS.
This project is designed to practice webpage layout, 
navigation bars, course cards, categories, and responsive styling.

 Technologies Used

- HTML5
- CSS3

✨ Features

- Udemy-style navigation bar
- Search bar
- Course categories
- Recommended topics section
- Popular courses section
- Course cards with images, ratings, and prices
- Simple and clean UI

📌 Project

This project was created for learning and practicing HTML & CSS
web development by recreating the basic design of the Udemy website.
